# Plan 2b: Port the visual revision into the app

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Next.js app match the revised, owner-approved mockup: two alternating colourways (navy and concrete), the realistic lanyard hero with the owner's photo on the badge, and the decorated one-page CV with the owner's cut-out portrait.

**Architecture:** The mockup (`mockup/index.html`, `mockup/styles.css`, `mockup/cv.html`) is the visual source of truth. The app's `src/app/site.css` is a 1:1 port of the mockup's CSS as it stood at commit `354c474`, so the home port replays the CSS diff `354c474..cedebe9` onto `site.css` (cedebe9 is the owner's second revision round: lanyard ring through the strap end, achievements reel, CV portrait back to 31mm). Data gains three profile columns (full name, badge photo, CV photo) and an achievement photo column, so the owner can change them in the editor. The CV component is rebuilt from `mockup/cv.html`.

**Tech Stack:** Next.js 16 (App Router, server components), React 19, Drizzle ORM + better-sqlite3, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-portfolio-cv-design.md`. The owner approved a visual revision on 2026-11-14 that supersedes the spec's colour wording (ultramarine is replaced by navy `#1D2640` and concrete `#E5E4DF`, alternating per section). `DESIGN.md` records the revised system. Where the spec and the mockup disagree on looks, the mockup wins; on behaviour and data, the spec wins.
