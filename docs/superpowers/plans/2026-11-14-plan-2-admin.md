# Plan 2: Admin Editor + Tailnet-only Access Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the owner a password-protected editor, reachable only inside their tailnet, that edits every list on the site, uploads images, and shows changes on the public site at once. Along the way, harden the public role: the DB connection is query-only, there is a nonce CSP plus security headers, and the first run shows a placeholder.

**Architecture:** There is one build and two roles, as before. `ROLE=admin` turns on `/admin/**`. The new `src/proxy.ts` (Next 16 renamed `middleware.ts` to `proxy.ts`) does two jobs. It 404s `/admin` unless the role is admin and Tailscale's identity header names the owner. It also stamps a per-request CSP nonce on every page. Auth uses argon2id and sessions stored as sha256 digests, with a 14-day rolling expiry and a lockout after 5 failures in 15 minutes. The editors are driven by a field registry (`src/admin/fields.ts`, `src/admin/resources.ts`): one generic list page, one generic form, and one generic store run every content table, so validation lives in one place. Public pages are already `force-dynamic` and read SQLite on every request, so a save shows on the public site at once without any revalidation endpoint.

**Tech Stack:**
- Next.js 16.4 (App Router, `proxy.ts`, server actions, `useActionState`) and React 19.3.
- Drizzle 0.45 on better-sqlite3 12.
- `@node-rs/argon2`, `sharp`, `server-only`, `@axe-core/playwright`.
- Vitest 5, Playwright 1.65, pnpm 10, Node 23 (LTS at deploy).

**Spec:** `docs/superpowers/specs/2026-11-14-portfolio-cv-design.md`. Visual authority: `DESIGN.md`. Carried-in debts: `docs/superpowers/plans/2026-11-14-plan-1-followups.md` ("Start of Plan 2" section).

**Spec amendments made by this plan.** Each one is recorded in the spec's new section 14 by Task 11. Each entry gives what changed, why, and the cost if it turns out wrong.
1. **No revalidate endpoint or `REVALIDATE_SECRET`.**
   - Why: public routes are `force-dynamic` and read SQLite per request, so a save is visible on the next request.
   - Cost if wrong: if a public route is ever made static, it needs `revalidatePath` again.
2. **Migrations run only from the CLIs.**
   - What: no process migrates at boot. Only `pnpm db:migrate` (and `pnpm db:seed`) migrate. The public role opens the existing file with `fileMustExist` and `PRAGMA query_only`, which closes the race from spec §3. A plain read-only open was not used, because it is fragile with WAL.
   - Cost if wrong: a deploy that forgets `pnpm db:migrate` fails loudly at the first query.
3. **The admin identity check is `ADMIN_TAILSCALE_LOGIN` and fails closed.**
   - What: if the variable is unset in the admin role, `/admin` is a 404. `next dev` skips only the header check, so the owner can work locally.
   - Cost if wrong: one extra env var at deploy.
4. **Reordering uses Move up and Move down buttons, not drag.**
   - Why: buttons are keyboard and screen-reader friendly, and WCAG 2.2 SC 2.5.7 requires a non-drag path anyway.
   - Cost if wrong: drag can be added later on top of the same `moveItem`.
5. **The Selected work layout comes from position (wide, half, half, wide), as DESIGN.md fixes the rhythm.**
   - What: the editor does not expose `projects.layout`; the column stays and is ignored.
   - Cost if wrong: none for the public site.
6. **Schema additions are limited to what Plan 2 uses.**
   - Added: `media.variants` and the auth tables. `admin_user.totpSecret` is not added.
   - Deferred until a surface shows them: `profile.remoteOk`, `achievements.category` and `achievements.mediaId`.
7. **Case study content moves to Plan 3.**
   - What: the approved case study mockup (`mockup/project.html`) is structured (problem, role, decisions, architecture booths, results, demo, gallery, next steps), not one markdown blob. Its fields, editor and `/projects/[slug]` page are built together in Plan 3, so `caseStudyMd` is not shown in the Plan 2 editor.
8. **Uploads go through a server action.**
   - What: `serverActions.bodySizeLimit` and `proxyClientMaxBodySize` are both raised to `16mb`, for the 15 MB cap plus multipart overhead.
9. **CSP keeps `style-src 'self' 'unsafe-inline'`.**
   - Why: React renders `style` attributes (card art positions, field colours), and nonces cannot cover attributes. Scripts stay nonce plus `'strict-dynamic'`.
   - Change: `frame-ancestors 'self'` (not `'none'`), so the Plan 3 CV builder can frame its own preview.

## Global Constraints

**Content and design**
- Content language: English. Zero em dashes (`—`) and zero en dashes (`–`) in any user-visible string, including every message the editor shows. Use a comma, colon, full stop, or hyphen.
- DESIGN.md is authoritative for tokens, components, states, motion and mobile rules. The editor reuses its tokens (`--ground`, `--stock`, `--ink`, `--ink-2`, `--on-ground-2`, radii, shadows) and buttons (`.btn`, `.btn-ink`, `.btn-ink-line`, `.btn-line`). It adds no new colours, fonts or effects. State shows by form and printed words, never by a second hue.
- No Tailwind. Editor styles live in `src/app/admin/admin.css`, with every class prefixed `adm-`.
- Accessibility: WCAG 2.2 AA.
  - Every control has a visible label.
  - Errors sit next to their field (`aria-invalid` plus `aria-describedby`).
  - Status messages use `role="status"`.
  - Everything works by keyboard.

**Next.js 16**
- Use `src/proxy.ts` exporting `proxy` and `config`. Never create `middleware.ts`.
- `cookies()`, `headers()`, `params` and `searchParams` are async.
- Read the matching guide in `node_modules/next/dist/docs/` before using an API you have not used in this repo (AGENTS.md).

**Security**
- The admin is never on Funnel.
- Every mutating server action starts with `await assertAdminAction()` (role, tailnet identity, same-origin check, session). Render-time gating is not a security boundary.
- Secrets and data are never committed: `.env*` and `.data*` are git-ignored.
- Uploads are re-encoded by sharp, get generated names, and are never written through a symlink.

**Tooling and commits**
- better-sqlite3 stays on `^12` (v13 segfaults on Node 23.1). Do not upgrade it in this plan.
- macOS shell: `sed -i ''`.
- TDD: write the failing test first for every unit with logic.

Replace `src/db/client.ts` with:

```ts
import "server-only";
import Database from "better-sqlite3";
import { drizzle, type BetterSQLite3Database } from "drizzle-orm/better-sqlite3";
import { migrate } from "drizzle-orm/better-sqlite3/migrator";
import fs from "node:fs";
import path from "node:path";
import { dataDir } from "@/lib/env";
import { isAdminRole } from "@/lib/role";
import * as schema from "./schema";

export type Db = BetterSQLite3Database<typeof schema>;
export type OpenOptions = { mustExist?: boolean; queryOnly?: boolean };

/** Open a SQLite file (or ":memory:") with WAL and foreign keys on. Never migrates: see migrateDb. */
export function openDb(file: string, opts: OpenOptions = {}): Db {
  if (file !== ":memory:" && !opts.mustExist) fs.mkdirSync(path.dirname(file), { recursive: true });
  const sqlite = new Database(file, { fileMustExist: Boolean(opts.mustExist) });
  sqlite.pragma("journal_mode = WAL");
  sqlite.pragma("busy_timeout = 5000");
  sqlite.pragma("foreign_keys = ON");
  if (opts.queryOnly) sqlite.pragma("query_only = ON");
  return drizzle(sqlite, { schema });
}

/** Apply pending migrations from ./drizzle. Only the CLIs call this (`pnpm db:migrate`, `pnpm db:seed`). */
export function migrateDb(db: Db): Db {
  migrate(db, { migrationsFolder: path.join(/*turbopackIgnore: true*/ process.cwd(), "drizzle") });
  return db;
}

export function dbFile(): string {
  return path.join(dataDir(), "portfolio.db");
}

// One connection per process. globalThis survives dev HMR module reloads; a module-level variable does not.
const g = globalThis as typeof globalThis & { __portfolioDb?: Db };

/** The process-wide connection. The public role is query-only, so it can never write or race a migration. */
export function getDb(): Db {
  g.__portfolioDb ??= openDb(dbFile(), { mustExist: true, queryOnly: !isAdminRole() });
  return g.__portfolioDb;
}
```

```ts
import type { Role } from "./role";

/** Header `tailscale serve` adds for tailnet users; Tailscale strips any copy a client sends. */
export const ADMIN_LOGIN_HEADER = "tailscale-user-login";

export function isAdminPath(pathname: string): boolean {
  return pathname === "/admin" || pathname.startsWith("/admin/");
}

/**
 * Defense in depth behind `tailscale serve`: the identity header must name the owner (ADMIN_TAILSCALE_LOGIN).
 * Fails closed when the expected login is not configured. `next dev` skips it so the owner can work locally.
 */
export function adminIdentityOk(input: { login: string | null; expectedLogin: string | undefined; dev: boolean }): boolean {
  if (input.dev) return true;
  const want = input.expectedLogin?.trim().toLowerCase();
  if (!want) return false;
  return (input.login ?? "").trim().toLowerCase() === want;
}

export function guardAdminRequest(input: {
  pathname: string;
  role: Role;
  login: string | null;
  expectedLogin: string | undefined;
  dev: boolean;
}): "pass" | "not-found" {
  if (!isAdminPath(input.pathname)) return "pass";
  if (input.role !== "admin") return "not-found";
  return adminIdentityOk(input) ? "pass" : "not-found";
}

/**
 * CSRF check for server actions. Next lets a request with no Origin header through with only a warning,
 * so the editor requires one, and its host must equal the request host.
 */
export function sameOrigin(origin: string | null, host: string | null): boolean {
  if (!origin || !host) return false;
  try {
    return new URL(origin).host.toLowerCase() === host.toLowerCase();
  } catch {
    return false;
  }
}
```

```ts
/**
 * Content Security Policy for every rendered page. Scripts: nonce + 'strict-dynamic' (Next adds the nonce to its
 * own scripts when it sees this header on the request). Styles keep 'unsafe-inline' because React renders style
 * attributes (card art positions, field colours) and nonces cannot cover attributes.
 */
export function buildCsp(nonce: string, dev: boolean): string {
  return [
    "default-src 'self'",
    `script-src 'self' 'nonce-${nonce}' 'strict-dynamic'${dev ? " 'unsafe-eval'" : ""}`,
    "style-src 'self' 'unsafe-inline'",
    "img-src 'self' data: blob:",
    "font-src 'self'",
    "media-src 'self'",
    "connect-src 'self'",
    "object-src 'none'",
    "base-uri 'self'",
    "form-action 'self'",
    "frame-ancestors 'self'",
  ].join("; ");
}

export function newNonce(): string {
  return Buffer.from(crypto.randomUUID()).toString("base64");
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";
import { ADMIN_LOGIN_HEADER, guardAdminRequest } from "@/lib/admin-guard";
import { buildCsp, newNonce } from "@/lib/csp";
import { role } from "@/lib/role";

/**
 * 1. /admin is a 404 unless ROLE=admin and Tailscale's identity header names the owner.
 * 2. Every rendered page gets a fresh CSP nonce (request header x-nonce + the CSP header on both sides).
 */
export function proxy(request: NextRequest) {
  const dev = process.env.NODE_ENV === "development";
  const verdict = guardAdminRequest({
    pathname: request.nextUrl.pathname,
    role: role(),
    login: request.headers.get(ADMIN_LOGIN_HEADER),
    expectedLogin: process.env.ADMIN_TAILSCALE_LOGIN,
    dev,
  });
  if (verdict === "not-found") {
    return new NextResponse("Not found", { status: 404, headers: { "content-type": "text/plain; charset=utf-8" } });
  }

  const nonce = newNonce();
  const csp = buildCsp(nonce, dev);
  const requestHeaders = new Headers(request.headers);
  requestHeaders.set("x-nonce", nonce);
  requestHeaders.set("content-security-policy", csp);
  const response = NextResponse.next({ request: { headers: requestHeaders } });
  response.headers.set("content-security-policy", csp);
  return response;
}

      missing: [
        { type: "header", key: "next-router-prefetch" },
```

```ts
import { hash, verify } from "@node-rs/argon2";

export const MIN_PASSWORD = 12;

/** argon2id with the library defaults (19 MiB, 2 passes, 1 lane): the OWASP baseline. */
export function hashPassword(password: string): Promise<string> {
  return hash(password);
}

/** False for a wrong password and for a malformed hash; never throws. */
export async function verifyPassword(passwordHash: string, password: string): Promise<boolean> {
  try {
    return await verify(passwordHash, password);
  } catch {
    return false;
  }
}

export function passwordProblem(password: string, confirm: string): string | null {
  if (password.length < MIN_PASSWORD) return `Use at least ${MIN_PASSWORD} characters.`;
  if (password.length > 256) return "Use at most 256 characters.";
  if (password !== confirm) return "The two passwords do not match.";
  return null;
}
```

Create `src/auth/lockout.ts`:

```ts
export const MAX_FAILURES = 5;
export const WINDOW_MS = 15 * 60_000;
export const LOCK_MS = 15 * 60_000;

export type Attempt = { at: Date; ok: boolean };

/**
 * Spec §6: after 5 failed attempts in 15 minutes, a 15-minute lockout.
 * `attempts` must be newest first. Returns when the lock lifts, or null when sign-in is allowed.
 */
export function lockedUntil(attempts: Attempt[], now: Date): Date | null {
  const failures: Date[] = [];
  for (const a of attempts) {
    if (a.ok) break;
    failures.push(a.at);
    if (failures.length === MAX_FAILURES) break;
  }
  if (failures.length < MAX_FAILURES) return null;
  const newest = failures[0];
  const oldest = failures[failures.length - 1];
  if (newest.getTime() - oldest.getTime() > WINDOW_MS) return null;
  const until = new Date(newest.getTime() + LOCK_MS);
  return until.getTime() > now.getTime() ? until : null;
}
```

Create `src/auth/session.ts`:

```ts
import crypto from "node:crypto";
import { eq, lt } from "drizzle-orm";
import type { Db } from "@/db/client";
import { sessions } from "@/db/schema";

export const SESSION_DAYS = 14;
const DAY = 86_400_000;

export type Session = { id: string; expiresAt: Date; renewed: boolean };

const digest = (token: string) => crypto.createHash("sha256").update(token).digest("hex");

/** A fresh 256-bit token. Only its sha256 is stored, so a copied database cannot be replayed as a cookie. */
export function createSession(db: Db, userAgent: string, now: Date): { token: string; expiresAt: Date } {
  const token = crypto.randomBytes(32).toString("base64url");
  const expiresAt = new Date(now.getTime() + SESSION_DAYS * DAY);
  db.delete(sessions).where(lt(sessions.expiresAt, now)).run();
  db.insert(sessions).values({ id: digest(token), expiresAt, createdAt: now, userAgent: userAgent.slice(0, 300) }).run();
  return { token, expiresAt };
}

/** Rolling expiry: a session used a day or more after its last renewal moves out to 14 days from now. */
export function readSession(db: Db, token: string, now: Date): Session | null {
  if (!token) return null;
  const id = digest(token);
  const row = db.select().from(sessions).where(eq(sessions.id, id)).get();
  if (!row) return null;
  if (row.expiresAt.getTime() <= now.getTime()) {
    db.delete(sessions).where(eq(sessions.id, id)).run();
    return null;
  }
  const fresh = new Date(now.getTime() + SESSION_DAYS * DAY);
  if (fresh.getTime() - row.expiresAt.getTime() >= DAY) {
    db.update(sessions).set({ expiresAt: fresh }).where(eq(sessions.id, id)).run();
    return { id, expiresAt: fresh, renewed: true };
  }
  return { id, expiresAt: row.expiresAt, renewed: false };
}

export function deleteSession(db: Db, token: string): void {
  db.delete(sessions).where(eq(sessions.id, digest(token))).run();
}
```

```ts
import { desc, lt } from "drizzle-orm";
import type { Db } from "@/db/client";
import { adminUser, loginAttempts } from "@/db/schema";
import { lockedUntil } from "./lockout";
import { hashPassword, passwordProblem, verifyPassword } from "./password";
import { createSession } from "./session";

export type AuthResult =
  | { ok: true; token: string; expiresAt: Date }
  | { ok: false; error: string; needsSetup?: boolean };

const ALREADY_SET = "A password is already set. Sign in instead.";

export function hasAdmin(db: Db): boolean {
  return db.select({ id: adminUser.id }).from(adminUser).get() !== undefined;
}

export async function attemptLogin(db: Db, password: string, userAgent: string, now: Date): Promise<AuthResult> {
  const user = db.select().from(adminUser).get();
  if (!user) return { ok: false, error: "Set a password first.", needsSetup: true };

  const recent = db
    .select({ at: loginAttempts.at, ok: loginAttempts.ok })
    .from(loginAttempts)
    .orderBy(desc(loginAttempts.at), desc(loginAttempts.id))
    .limit(10)
    .all();
  const until = lockedUntil(recent, now);
  if (until) {
    const minutes = Math.max(1, Math.ceil((until.getTime() - now.getTime()) / 60_000));
    return { ok: false, error: `Too many wrong passwords. Try again in ${minutes} ${minutes === 1 ? "minute" : "minutes"}.` };
  }

  const ok = password.length > 0 && (await verifyPassword(user.passwordHash, password));
  db.insert(loginAttempts).values({ at: now, ok }).run();
  db.delete(loginAttempts).where(lt(loginAttempts.at, new Date(now.getTime() - 86_400_000))).run();
  if (!ok) return { ok: false, error: "That password is not right." };
  return { ok: true, ...createSession(db, userAgent, now) };
}

/** First run only: sets the one owner password and signs in. */
export async function setupAdmin(db: Db, password: string, confirm: string, userAgent: string, now: Date): Promise<AuthResult> {
  if (hasAdmin(db)) return { ok: false, error: ALREADY_SET };
  const problem = passwordProblem(password, confirm);
  if (problem) return { ok: false, error: problem };
  const passwordHash = await hashPassword(password);
  try {
    db.insert(adminUser).values({ id: 1, passwordHash }).run();
  } catch {
    return { ok: false, error: ALREADY_SET }; // lost a race with another setup request
  }
  return { ok: true, ...createSession(db, userAgent, now) };
}
```

```ts
import { isAdminRole } from "@/lib/role";
import { readSession, type Session } from "./session";

export const SESSION_COOKIE = "pf_admin";

async function identityOk(): Promise<boolean> {
  const h = await headers();
  return adminIdentityOk({
    login: h.get(ADMIN_LOGIN_HEADER),
    expectedLogin: process.env.ADMIN_TAILSCALE_LOGIN,
    dev: process.env.NODE_ENV === "development",
  });
}

export async function currentSession(): Promise<Session | null> {
  const token = (await cookies()).get(SESSION_COOKIE)?.value;
  return token ? readSession(getDb(), token, new Date()) : null;
}

/** Sign in and setup pages: the admin role and the owner's tailnet identity, no session. Anything else is a 404. */
export async function requireAdminArea(): Promise<void> {
  if (!isAdminRole() || !(await identityOk())) notFound();
}

/** Every other editor page. Layouts do not re-run on client navigation, so each page calls this too. */
export async function requireAdminPage(): Promise<Session> {
  await requireAdminArea();
  const session = await currentSession();
  if (!session) redirect("/admin/login");
  return session;
}

/**
 * First line of every mutating server action. An action is a public POST endpoint whatever page renders it,
 * so this re-checks the role, the tailnet identity, the Origin header and (unless signing in) the session.
 */
export async function assertAdminAction({ needSession = true }: { needSession?: boolean } = {}): Promise<void> {
  if (!isAdminRole() || !(await identityOk())) throw new Error("Not found");
  const h = await headers();
  if (!sameOrigin(h.get("origin"), h.get("x-forwarded-host") ?? h.get("host"))) {
    throw new Error("Refused a cross-origin request.");
  }
  if (!needSession) return;
  const session = await currentSession();
  if (!session) redirect("/admin/login");
  if (session.renewed) {
    const token = (await cookies()).get(SESSION_COOKIE)!.value;
    await setSessionCookie(token, session.expiresAt);
  }
}

export async function setSessionCookie(token: string, expiresAt: Date): Promise<void> {
  (await cookies()).set(SESSION_COOKIE, token, {
    httpOnly: true,
    secure: true, // tailscale serve terminates HTTPS; browsers also accept Secure cookies on 127.0.0.1
    sameSite: "strict",
    path: "/",
    expires: expiresAt,
  });
}

/** Removes the cookie and returns the token it held, so the caller can delete the session row. */
export async function clearSessionCookie(): Promise<string | undefined> {
  const store = await cookies();
  const token = store.get(SESSION_COOKIE)?.value;
  store.delete(SESSION_COOKIE);
  return token;
}
```

```ts
import { attemptLogin, setupAdmin } from "@/auth/login";
import { deleteSession } from "@/auth/session";
import { getDb } from "@/db/client";

export type AuthFormState = { error?: string };

const userAgent = async () => (await headers()).get("user-agent") ?? "";
const field = (form: FormData, name: string) => String(form.get(name) ?? "");

export async function login(_prev: AuthFormState, form: FormData): Promise<AuthFormState> {
  await assertAdminAction({ needSession: false });
  const result = await attemptLogin(getDb(), field(form, "password"), await userAgent(), new Date());
  if (!result.ok) {
    if (result.needsSetup) redirect("/admin/setup");
    return { error: result.error };
  }
  await setSessionCookie(result.token, result.expiresAt);
  redirect("/admin");
}

export async function setup(_prev: AuthFormState, form: FormData): Promise<AuthFormState> {
  await assertAdminAction({ needSession: false });
  const result = await setupAdmin(getDb(), field(form, "password"), field(form, "confirm"), await userAgent(), new Date());
  if (!result.ok) return { error: result.error };
  await setSessionCookie(result.token, result.expiresAt);
  redirect("/admin");
}

export async function logout(): Promise<void> {
  await assertAdminAction({ needSession: false });
  const token = await clearSessionCookie();
  if (token) deleteSession(getDb(), token);
  redirect("/admin/login");
}
```

```ts
/** Field definitions for the editors, and the parser that turns submitted strings into column values. */
import type { CardArt } from "@/db/schema";

export type FieldKind =
  | "text" | "textarea" | "url" | "email" | "slug" | "color" | "number" | "bool" | "enum" | "tags" | "lines" | "media" | "cardArt";
export type MediaKind = "screenshot" | "photo" | "logo";

export type Field = {
  name: string;
  label: string;
  kind: FieldKind;
  /** Empty input allowed: "null" stores null (nullable column), "blank" stores "" or [] (NOT NULL column). */
  empty?: "null" | "blank";
  help?: string;
  options?: readonly string[];
  mediaKind?: MediaKind;
  min?: number;
  max?: number;
  rows?: number;
};

export type Parsed = { values: Record<string, unknown>; errors: Record<string, string> };
type One = { value: unknown } | { error: string };

export const LONG_DASH_ERROR = "Use a comma, colon or full stop instead of a long dash.";
const LONG_DASH = /[\u2013\u2014]/;
const DEFAULT_MAX = { text: 200, textarea: 4000 } as const;

export function parseFields(fields: readonly Field[], form: FormData): Parsed {
  const values: Record<string, unknown> = {};
  const errors: Record<string, string> = {};
  for (const f of fields) {
    const raw = form.get(f.name);
    const r = parseField(f, typeof raw === "string" ? raw : null);
    if ("error" in r) errors[f.name] = r.error;
    else values[f.name] = r.value;
  }
  return { values, errors };
}

export function parseField(f: Field, raw: string | null): One {
  if (f.kind === "bool") return { value: raw === "on" };
  const s = (raw ?? "").replace(/\r\n?/g, "\n").trim();
  if (s === "") {
    if (f.empty === "null") return { value: null };
    if (f.empty === "blank") return { value: f.kind === "tags" || f.kind === "lines" ? [] : "" };
    return { error: "Fill this in." };
  }
  if (f.kind !== "cardArt" && LONG_DASH.test(s)) return { error: LONG_DASH_ERROR };
  switch (f.kind) {
    case "text":
    case "textarea": {
      const max = f.max ?? DEFAULT_MAX[f.kind];
      return s.length > max ? { error: `Keep it under ${max} characters.` } : { value: s };
    }
    case "url":
      return parseUrl(s);
    case "email":
      return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(s) ? { value: s } : { error: "Enter an email address like name@example.com." };
    case "slug":
      return /^[a-z0-9]+(?:-[a-z0-9]+)*$/.test(s) && s.length <= 60
        ? { value: s }
        : { error: "Use lowercase letters, numbers and single hyphens, like my-project." };
    case "color":
      return /^#[0-9a-f]{6}$/i.test(s) ? { value: s.toLowerCase() } : { error: "Use a hex colour like #ff6a2b." };
    case "number": {
      const n = Number(s);
      if (!Number.isFinite(n)) return { error: "Enter a number." };
      if ((f.min !== undefined && n < f.min) || (f.max !== undefined && n > f.max)) {
        return { error: `Use a number from ${f.min} to ${f.max}.` };
      }
      return { value: n };
    }
    case "enum":
      return f.options?.includes(s) ? { value: s } : { error: "Pick one of the options." };
    case "tags": {
      const tags = s.split(",").map((t) => t.trim()).filter(Boolean);
      if (tags.length > 12) return { error: "Use at most 12 tags." };
      if (tags.some((t) => t.length > 40)) return { error: "Keep each tag under 40 characters." };
      return { value: tags };
    }
    case "lines": {
      const lines = s.split("\n").map((l) => l.trim()).filter(Boolean);
      if (lines.some((l) => l.length > 300)) return { error: "Keep each line under 300 characters." };
      return { value: lines };
    }
    case "media":
      return /^\d+$/.test(s) ? { value: Number(s) } : { error: "Pick an image from the list." };
    case "cardArt":
      return parseCardArt(s);
    default:
      return { error: "This field type is not supported." };
  }
}

function parseUrl(s: string): One {
  let u: URL;
  try {
    u = new URL(s);
  } catch {
    return { error: "Enter a full address starting with https://" };
  }
  if (u.protocol !== "https:" && u.protocol !== "http:") return { error: "Use an http or https address." };
  u.pathname = u.pathname.replace(/\/{2,}/g, "/");
  return { value: u.pathname === "/" && !u.search && !u.hash ? u.origin : u.toString() };
}

const isNum = (v: unknown): v is number => typeof v === "number" && Number.isFinite(v);
const isObj = (v: unknown): v is Record<string, unknown> => typeof v === "object" && v !== null && !Array.isArray(v);
const PATH_D = /^[MLHVCSQTAZmlhvcsqtaz0-9.,\s-]{1,400}$/;
const OBJECT_POSITION = /^[a-z0-9.%\s-]{1,40}$/i;

/** Card art is rendered into SVG and inline styles, so only known keys with numbers and path syntax survive. */
export function parseCardArt(s: string): One {
  let v: unknown;
  try {
    v = JSON.parse(s);
  } catch {
    return { error: "This is not valid JSON." };
  }
  if (!isObj(v) || !isObj(v.print) || !isObj(v.leader) || !isObj(v.pin)) return { error: "Card layout needs print, leader and pin." };
  const { print, leader, pin } = v;
  if (!["left", "top", "width", "height", "rot"].every((k) => isNum(print[k]))) {
    return { error: "print needs numbers for left, top, width, height and rot." };
  }
  if (print.objectPosition !== undefined && !(typeof print.objectPosition === "string" && OBJECT_POSITION.test(print.objectPosition))) {
    return { error: 'print.objectPosition must look like "top left" or "50% 0".' };
  }
  if (typeof leader.d !== "string" || !PATH_D.test(leader.d)) {
    return { error: "leader.d must be SVG path commands and numbers, like M 10 20 L 30 40." };
  }
  if (!isObj(leader.dot) || !isNum(leader.dot.x) || !isNum(leader.dot.y)) return { error: "leader.dot needs numbers for x and y." };
  if (!isNum(pin.x) || !isNum(pin.y) || (pin.side !== "l" && pin.side !== "r")) {
    return { error: 'pin needs numbers for x and y, and side "l" or "r".' };
  }
  for (const flag of [leader.ink, pin.big, pin.ink]) {
    if (flag !== undefined && typeof flag !== "boolean") return { error: "big and ink must be true or false." };
  }
  const art: CardArt = {
    print: {
      left: print.left as number, top: print.top as number, width: print.width as number,
      height: print.height as number, rot: print.rot as number,
      ...(typeof print.objectPosition === "string" ? { objectPosition: print.objectPosition } : {}),
    },
    leader: {
      d: leader.d,
      dot: { x: leader.dot.x, y: leader.dot.y },
      ...(typeof leader.ink === "boolean" ? { ink: leader.ink } : {}),
    },
    pin: {
      x: pin.x, y: pin.y, side: pin.side,
      ...(typeof pin.big === "boolean" ? { big: pin.big } : {}),
      ...(typeof pin.ink === "boolean" ? { ink: pin.ink } : {}),
    },
  };
  return { value: art };
}

/** A stored row as the strings the form shows. A missing row gives empty strings. */
export function toFormValues(fields: readonly Field[], row: Record<string, unknown> | undefined): Record<string, string> {
  const out: Record<string, string> = {};
  for (const f of fields) {
    const v = row?.[f.name];
    if (f.kind === "bool") out[f.name] = v ? "on" : "";
    else if (v === null || v === undefined) out[f.name] = "";
    else if (f.kind === "tags") out[f.name] = (v as string[]).join(", ");
    else if (f.kind === "lines") out[f.name] = (v as string[]).join("\n");
    else if (f.kind === "cardArt") out[f.name] = JSON.stringify(v, null, 2);
    else out[f.name] = String(v);
  }
  return out;
}

/** The raw submitted strings, so a form that failed validation shows exactly what the owner typed. */
export function echoValues(fields: readonly Field[], form: FormData): Record<string, string> {
  const out: Record<string, string> = {};
  for (const f of fields) {
    const raw = form.get(f.name);
    out[f.name] = f.kind === "bool" ? (raw === "on" ? "on" : "") : typeof raw === "string" ? raw : "";
  }
  return out;
}
```

```ts
import { and, asc, eq, ne, sql } from "drizzle-orm";
import type { Db } from "@/db/client";
import { cvProfileItems, media, profile, projects } from "@/db/schema";
import { RESOURCES, type Flag, type ListKey, type Resource } from "./resources";

export const MAX_FEATURED = 4;
export type Row = Record<string, unknown> & { id: number; sortOrder: number };
export type SaveResult = { ok: true; id: number } | { ok: false; errors: Record<string, string> };
export type FlagResult = { ok: true } | { ok: false; error: "unknown-flag" | "featured-cap" };

// Drizzle's builders are typed per table. Every list table shares listCols() (src/db/schema.ts) and the registry
// names only real columns (tests/unit/store.test.ts checks this), so the builders use one representative table type.
const tableOf = (key: ListKey) => RESOURCES[key].table as unknown as typeof projects;

export function listItems(db: Db, key: ListKey): Row[] {
  const t = tableOf(key);
  return db.select().from(t).orderBy(asc(t.sortOrder), asc(t.id)).all() as Row[];
}

export function getItem(db: Db, key: ListKey, id: number): Row | undefined {
  const t = tableOf(key);
  return db.select().from(t).where(eq(t.id, id)).get() as Row | undefined;
}

export function saveItem(db: Db, key: ListKey, id: number | null, values: Record<string, unknown>): SaveResult {
  const res = RESOURCES[key];
  const errors = checkRules(db, res, id, values);
  if (Object.keys(errors).length > 0) return { ok: false, errors };
  const t = tableOf(key);
  if (id === null) {
    const { max } = db.select({ max: sql<number>`coalesce(max(${t.sortOrder}), 0)` }).from(t).get()!;
    const row = db
      .insert(t)
      .values({ ...res.hidden, ...values, sortOrder: max + 1 } as never)
      .returning({ id: t.id })
      .get();
    return { ok: true, id: row.id };
  }
  const result = db.update(t).set({ ...values, updatedAt: new Date() } as never).where(eq(t.id, id)).run();
  if (result.changes === 0) return { ok: false, errors: { _form: "This item no longer exists." } };
  return { ok: true, id };
}

/** Also drops the item from every CV profile: cv_profile_items has no foreign key to the six list tables. */
export function deleteItem(db: Db, key: ListKey, id: number): void {
  const t = tableOf(key);
  db.transaction((tx) => {
    tx.delete(cvProfileItems)
      .where(and(eq(cvProfileItems.itemType, RESOURCES[key].cvItemType), eq(cvProfileItems.itemId, id)))
      .run();
    tx.delete(t).where(eq(t.id, id)).run();
  });
}

/** Swap with the neighbour above (-1) or below (1), then renumber 1..n so old gaps and ties disappear. */
export function moveItem(db: Db, key: ListKey, id: number, dir: -1 | 1): boolean {
  const rows = listItems(db, key);
  const i = rows.findIndex((r) => r.id === id);
  const j = i + dir;
  if (i < 0 || j < 0 || j >= rows.length) return false;
  [rows[i], rows[j]] = [rows[j], rows[i]];
  const t = tableOf(key);
  db.transaction((tx) => {
    rows.forEach((r, n) => {
      tx.update(t).set({ sortOrder: n + 1 } as never).where(eq(t.id, r.id)).run();
    });
  });
  return true;
}

export function setFlag(db: Db, key: ListKey, id: number, flag: Flag, value: boolean): FlagResult {
  if (!RESOURCES[key].flags.includes(flag)) return { ok: false, error: "unknown-flag" };
  if (flag === "featured" && value && featuredOthers(db, id) >= MAX_FEATURED) return { ok: false, error: "featured-cap" };
  const t = tableOf(key);
  db.update(t).set({ [flag]: value, updatedAt: new Date() } as never).where(eq(t.id, id)).run();
  return { ok: true };
}

/** The profile is one row with id 1: the first save creates it, later saves update it. */
export function saveProfile(db: Db, values: Record<string, unknown>): void {
  db.insert(profile)
    .values({ id: 1, ...values } as never)
    .onConflictDoUpdate({ target: profile.id, set: { ...values, updatedAt: new Date() } as never })
    .run();
}

function featuredOthers(db: Db, id: number | null): number {
  return db.$count(projects, id === null ? eq(projects.featured, true) : and(eq(projects.featured, true), ne(projects.id, id)));
}

function checkRules(db: Db, res: Resource, id: number | null, values: Record<string, unknown>): Record<string, string> {
  const errors: Record<string, string> = {};
  for (const f of res.fields) {
    if (f.kind !== "media" || !(f.name in values) || values[f.name] === null) continue;
    const picked = db.select({ kind: media.kind }).from(media).where(eq(media.id, values[f.name] as number)).get();
    if (!picked || picked.kind !== f.mediaKind) errors[f.name] = `Pick a ${f.mediaKind} from the media library.`;
  }
  if (res.key === "projects") {
    if (typeof values.slug === "string") {
      const sameSlug = eq(projects.slug, values.slug);
      const clash = db
        .select({ id: projects.id })
        .from(projects)
        .where(id === null ? sameSlug : and(sameSlug, ne(projects.id, id)))
        .get();
      if (clash) errors.slug = "Another project already uses this slug.";
    }
    if (values.featured === true && featuredOthers(db, id) >= MAX_FEATURED) {
      errors.featured = `Only ${MAX_FEATURED} projects can be featured. Unfeature another one first.`;
    }
  }
  return errors;
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { redirect } from "next/navigation";
import { assertAdminAction } from "@/auth/admin";
import { getDb } from "@/db/client";
import { echoValues, parseFields, toFormValues } from "./fields";
import { getResource, PROFILE_FIELDS, type Flag, type Resource } from "./resources";
import { deleteItem, moveItem, saveItem, saveProfile, setFlag } from "./store";

export type FormState = {
  status: "idle" | "saved" | "error";
  message?: string;
  errors: Record<string, string>;
  values?: Record<string, string>;
};

// Bound arguments arrive from the browser like any other input, so each one is checked again here.
function resourceFor(key: unknown): Resource {
  const res = typeof key === "string" ? getResource(key) : undefined;
  if (!res) throw new Error("Unknown list");
  return res;
}
function idFrom(id: unknown): number {
  if (typeof id !== "number" || !Number.isInteger(id) || id < 1) throw new Error("Bad id");
  return id;
}

export async function saveResource(key: string, id: number | null, _prev: FormState, form: FormData): Promise<FormState> {
  await assertAdminAction();
  const res = resourceFor(key);
  const rowId = id === null ? null : idFrom(id);
  const parsed = parseFields(res.fields, form);
  if (Object.keys(parsed.errors).length > 0) {
    return { status: "error", errors: parsed.errors, values: echoValues(res.fields, form) };
  }
  const result = saveItem(getDb(), res.key, rowId, parsed.values);
  if (!result.ok) {
    return { status: "error", errors: result.errors, message: result.errors._form, values: echoValues(res.fields, form) };
  }
  revalidatePath(`/admin/${res.key}`);
  if (rowId === null) redirect(`/admin/${res.key}/${result.id}?saved=1`);
  return { status: "saved", errors: {}, values: toFormValues(res.fields, parsed.values) };
}

export async function deleteResource(key: string, id: number): Promise<void> {
  await assertAdminAction();
  const res = resourceFor(key);
  deleteItem(getDb(), res.key, idFrom(id));
  revalidatePath(`/admin/${res.key}`);
  redirect(`/admin/${res.key}?notice=deleted`);
}

export async function moveResource(key: string, id: number, dir: number): Promise<void> {
  await assertAdminAction();
  const res = resourceFor(key);
  if (dir !== 1 && dir !== -1) throw new Error("Bad direction");
  moveItem(getDb(), res.key, idFrom(id), dir);
  revalidatePath(`/admin/${res.key}`);
}

export async function toggleResource(key: string, id: number, flag: Flag, value: boolean): Promise<void> {
  await assertAdminAction();
  const res = resourceFor(key);
  if (typeof value !== "boolean") throw new Error("Bad value");
  const result = setFlag(getDb(), res.key, idFrom(id), flag, value);
  if (!result.ok) redirect(`/admin/${res.key}?notice=${result.error}`);
  revalidatePath(`/admin/${res.key}`);
}

export async function saveProfileAction(_prev: FormState, form: FormData): Promise<FormState> {
  await assertAdminAction();
  const parsed = parseFields(PROFILE_FIELDS, form);
  if (Object.keys(parsed.errors).length > 0) {
    return { status: "error", errors: parsed.errors, values: echoValues(PROFILE_FIELDS, form) };
  }
  saveProfile(getDb(), parsed.values);
  revalidatePath("/admin", "layout");
  return { status: "saved", errors: {}, values: toFormValues(PROFILE_FIELDS, parsed.values) };
}
```

```tsx
      <div className="adm-field">
        <label className="adm-check"><input type="checkbox" {...a11y} defaultChecked={value === "on"} />{f.label}</label>
        {err}
        {help}
      </div>
    );
  }

  let control: React.ReactNode;
  if (f.kind === "textarea" || f.kind === "lines" || f.kind === "cardArt") {
    control = (
      <textarea
        className={`adm-input${f.kind === "cardArt" ? " is-code" : ""}`}
        rows={f.rows ?? 4} spellCheck={f.kind !== "cardArt"} defaultValue={value} {...a11y}
      />
    );
  } else if (f.kind === "enum") {
    control = (
      <select className="adm-input" defaultValue={value} {...a11y}>
        {(f.options ?? []).map((o) => <option key={o} value={o}>{o}</option>)}
      </select>

      </select>
```

```tsx
/**
 * Generic editor form. React resets uncontrolled fields after an action, so the action returns the values to show
 * next: the saved values after a save, or exactly what was typed after a validation error.

        : "";
  return (

      <p className="adm-status" data-kind={state.status} role="status">{message}</p>

      <div className="adm-actions">
        <button className="btn btn-ink" type="submit" disabled={pending}>{pending ? "Saving" : submitLabel}</button>
      </div>

  );
```

```ts
export const KIND_DIRS: Record<MediaKind, string> = { screenshot: "screens", photo: "photos", logo: "logos" };

export class UploadError extends Error {}
export type ProcessedUpload = { path: string; width: number; height: number; variants: MediaVariant[] };

/**
 * Validates by decoding (sharp), never by extension or MIME header. Re-encoding to WebP drops EXIF and anything
 * appended to the file. Names come from the content hash, never from the user.
 */
export async function processUpload(input: Buffer, kind: MediaKind, uploadsDir: string): Promise<ProcessedUpload> {
  if (input.byteLength === 0) throw new UploadError("Choose a file to upload.");
  if (input.byteLength > MAX_UPLOAD_BYTES) throw new UploadError("Files can be up to 15 MB.");
  let format: string | undefined;
  try {
    format = (await sharp(input).metadata()).format;
  } catch {
    throw new UploadError("That file is not an image.");
  }
  if (!format || !ACCEPTED_FORMATS.has(format)) throw new UploadError("Upload a JPEG, PNG, WebP or AVIF image.");

  const master = await sharp(input)
    .rotate()
    .resize({ width: MASTER_MAX_WIDTH, withoutEnlargement: true })
    .webp({ quality: 86 })
    .toBuffer({ resolveWithObject: true });
  const hash = crypto.createHash("sha256").update(master.data).digest("hex").slice(0, 12);
  const dir = KIND_DIRS[kind];
  await ensurePlainDir(path.join(uploadsDir, dir));
  const rel = `${dir}/${hash}.webp`;
  await writeNoFollow(path.join(uploadsDir, rel), master.data);

  const variants: MediaVariant[] = [];
  for (const width of VARIANT_WIDTHS) {
    if (width >= master.info.width) continue;
    const v = await sharp(master.data).resize({ width }).webp({ quality: 82 }).toBuffer({ resolveWithObject: true });
    const vrel = `${dir}/${hash}-${width}.webp`;
    await writeNoFollow(path.join(uploadsDir, vrel), v.data);
    variants.push({ width: v.info.width, height: v.info.height, path: vrel });
  }
  return { path: rel, width: master.info.width, height: master.info.height, variants };
}

async function ensurePlainDir(dir: string): Promise<void> {
  await fs.mkdir(dir, { recursive: true });
  const stat = await fs.lstat(dir);
  if (stat.isSymbolicLink() || !stat.isDirectory()) throw new UploadError("The uploads folder is not a plain directory.");
}

async function writeNoFollow(file: string, data: Buffer): Promise<void> {
  const { O_WRONLY, O_CREAT, O_TRUNC, O_NOFOLLOW } = fsSync.constants;
  const handle = await fs.open(file, O_WRONLY | O_CREAT | O_TRUNC | O_NOFOLLOW, 0o644);
  try {
    await handle.writeFile(data);
  } finally {
    await handle.close();
  }
}

/** The same image uploaded twice hashes to the same files, so the existing row is reused. */
export function createMedia(db: Db, upload: ProcessedUpload, meta: { kind: MediaKind; alt: string; provenance: string }): number {
  const existing = db.select({ id: media.id }).from(media).where(eq(media.path, upload.path)).get();
  if (existing) return existing.id;
  return db
    .insert(media)
    .values({
      path: upload.path, kind: meta.kind, width: upload.width, height: upload.height,
      alt: meta.alt, provenance: meta.provenance, variants: upload.variants,
    })
    .returning({ id: media.id })
    .get().id;
}

export function mediaUsage(db: Db, id: number): string[] {
  return [
    ...db.select({ name: projects.name }).from(projects).where(eq(projects.screenshotId, id)).all().map((r) => r.name),
    ...db.select({ name: activities.title }).from(activities).where(eq(activities.photoId, id)).all().map((r) => r.name),
  ];
}

export function listMedia(db: Db) {
  return db
    .select()
    .from(media)
    .orderBy(desc(media.id))
    .all()
    .map((m) => ({ ...m, usedBy: mediaUsage(db, m.id) }));
}

export function updateAlt(db: Db, id: number, alt: string): void {
  db.update(media).set({ alt, updatedAt: new Date() }).where(eq(media.id, id)).run();
}

export async function deleteMedia(db: Db, id: number, uploadsDir: string): Promise<{ ok: true } | { ok: false; error: string }> {
  const row = db.select().from(media).where(eq(media.id, id)).get();
  if (!row) return { ok: true };
  const usedBy = mediaUsage(db, id);
  if (usedBy.length > 0) return { ok: false, error: `Used by ${usedBy.join(", ")}. Pick another image there first.` };
  db.delete(media).where(eq(media.id, id)).run();
  for (const rel of [row.path, ...row.variants.map((v) => v.path)]) {
    const file = safeJoin(uploadsDir, rel.split("/"));
    if (file) await fs.rm(file, { force: true });
  }
  return { ok: true };
}
```

```ts
export type MediaFormState = { error?: string; done?: boolean };

function altProblem(alt: string): string | null {
  if (/[\u2013\u2014]/.test(alt)) return LONG_DASH_ERROR;
  if (alt.length > 300) return "Keep the alt text under 300 characters.";
  return null;
}

function idFrom(id: unknown): number {
  if (typeof id !== "number" || !Number.isInteger(id) || id < 1) throw new Error("Bad id");
  return id;
}

export async function uploadMedia(_prev: MediaFormState, form: FormData): Promise<MediaFormState> {
  await assertAdminAction();
  const file = form.get("file");
  const kind = String(form.get("kind") ?? "");
  const alt = String(form.get("alt") ?? "").trim();
  if (!(file instanceof File) || file.size === 0) return { error: "Choose a file to upload." };
  if (file.size > MAX_UPLOAD_BYTES) return { error: "Files can be up to 15 MB." };
  if (!Object.hasOwn(KIND_DIRS, kind)) return { error: "Pick what kind of image this is." };
  const problem = altProblem(alt);
  if (problem) return { error: problem };
  try {
    const upload = await processUpload(Buffer.from(await file.arrayBuffer()), kind as MediaKind, uploadsDir());
    createMedia(getDb(), upload, {
      kind: kind as MediaKind,
      alt,
      provenance: `Uploaded in the editor on ${new Date().toISOString().slice(0, 10)}.`,
    });
  } catch (e) {
    if (e instanceof UploadError) return { error: e.message };
    throw e;
  }
  revalidatePath("/admin/media");
  return { done: true };
}

export async function saveAlt(id: number, _prev: MediaFormState, form: FormData): Promise<MediaFormState> {
  await assertAdminAction();
  const alt = String(form.get("alt") ?? "").trim();
  const problem = altProblem(alt);
  if (problem) return { error: problem };
  updateAlt(getDb(), idFrom(id), alt);
  revalidatePath("/admin/media");
  return { done: true };
}

export async function removeMedia(id: number): Promise<void> {
  await assertAdminAction();
  const result = await deleteMedia(getDb(), idFrom(id), uploadsDir());
  revalidatePath("/admin/media");
  redirect(result.ok ? "/admin/media?notice=deleted" : "/admin/media?notice=in-use");
}
```
